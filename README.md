# Витрина «Хорошего источника»

Одна страница: **https://copybauer42.github.io/horoshiy-istochnik-vitrina/**
Открывается в любом браузере — без установки, без входа, без сервера.

## Что это

«Хороший источник» собирает из 31 источника (ленты и каналы Телеграма)
новости о **свершившихся созидательных делах** — сделано, а не обещано, —
раскладывает их по 44 темам и ведёт очередь редакции из 5 ступеней.

На витрине работает всё, кроме самого сбора:

- лента, две полки и очередь согласования;
- 47 тем по 11 разделам, выбор сразу нескольких, пометка «на стыке»;
- «почему такая рубрика» — какие слова и где сработали;
- кнопки очереди: поднять, отклонить с причиной, одобрить;
- **переключатель ступени** в настройках — набор кнопок на карточках
  меняется, и лестница редакции становится видна.

## Чего здесь нет — и это важно

Лента — **снимок обхода**, замерший на момент сборки. Новые новости сами
не появятся: страница статическая, к серверу не ходит и ничего не
собирает. Нажатия живут в браузере смотрящего и никуда не уходят —
закроете вкладку, и всё вернётся на место.

Живая лента с настоящим обходом работает отдельно, в расширении браузера
с ключом редакции.

## Откуда берётся эта страница

Собирается командой `python3 hi.py vitrina` из основного репозитория
проекта. Здесь лежит только результат — один файл, руками не правится.
